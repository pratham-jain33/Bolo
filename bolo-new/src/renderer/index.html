Context Awareness

What bolo may read from the app you are in, to spell names and to understand “this”.

Read the focused context
Lets the router tell “rewrite this” apart from a sentence that merely opens with “rewrite”. Off means an utterance is treated as plain dictation unless its words are unambiguous.
Open apps and files
Lets a spoken command launch an application, open a file or folder, or open a link. Off means bolo says it is not allowed instead of trying.
Take screenshots
Lets you ask for a picture of the screen. Nothing is captured unless you ask for it.
Edit files
Lets a spoken command read, create or change a file inside your home folder. Off by default: it can overwrite your work, and anything that would overwrite an existing file is refused rather than guessed at. Paths outside your home folder are always refused.
Private mode
Nothing you dictate is stored or used for training.

Extras

The parts that are bolo rather than the reference: your own model backend, local coding CLIs, and the two replay switches.

Model
—
API keys
Bring your own key. Keys never leave the main process, and rotate automatically when one is rate limited. Groq does transcription and the model; Deepgram does the voice. The provider selected here is the one Add, Rotate and Clear act on.
Coding agents
Hand a prompt to a local CLI agent. Nothing is sent anywhere by bolo itself; the CLIs use their own credentials.
Available intents
What the agent can be asked to do, and a demo workflow you can run.
Replay the intro
Run the cinematic opening again.
Restart onboarding
Wipes every setting back to its default and starts the setup flow again. API keys are kept. bolo restarts.
